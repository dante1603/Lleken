# Evidencias de Entrega - DevOps Lleken

Esta carpeta está destinada a almacenar las capturas de pantalla y evidencias del funcionamiento del entorno Docker, base de datos de Supabase y despliegue para tu informe de entrega final (EP2).

## Capturas Recomendadas a Guardar Aquí:

1. **Captura 1: Docker Desktop Abierto**
   - Muestra el motor de Docker (`Engine Running`) iniciado correctamente en Windows.
   - Nombre recomendado: `01_docker_desktop_running.png`

2. **Captura 2: Imágenes de Lleken Compiladas**
   - Muestra la pestaña de "Images" en Docker Desktop con `lleken-backend` y `lleken-frontend` compiladas como `latest`.
   - Nombre recomendado: `02_docker_images.png`

3. **Captura 3: Contenedores Activos**
   - Muestra los contenedores `lleken-backend` (puerto 8787) y `lleken-frontend` (puerto 3000) en estado `Running`.
   - Nombre recomendado: `03_docker_containers_active.png`

4. **Captura 4: Login en Localhost**
   - Pantalla del frontend en `http://localhost:3000/login` mostrando el botón de Google Auth.
   - Nombre recomendado: `04_login_localhost.png`

5. **Captura 5: Redirección a Vercel**
   - El resultado del login exitoso mostrando la redirección a `https://lleken.vercel.app/home` con los datos cargados.
   - Nombre recomendado: `05_vercel_redirect.png`
