# Indice rapido para agentes IA

Objetivo: que un agente nuevo pueda retomar Lleken sin leer todo `docs/`.

## Lectura minima

1. `AGENTS.md` - reglas operativas del repo.
2. `docs/ai-inbox/DAILY_BRIEF.md` - estado corto y foco inmediato.
3. `docs/ai-inbox/PENDING_TASKS.md` - solo si vas a tomar o crear una tarea delegable.
4. `docs/product/PRODUCT_VISION_COLLABORATIVE_CARE.md` - direccion canonica de producto desde 2026-07-10.
5. `docs/current/APP_OVERVIEW.md` - arquitectura y funcionalidad heredada vigente.
6. `docs/current/DATABASE_STATE.md` - verdad operativa de Supabase, Storage y datos.

## Leer segun dominio

- Refundacion de producto: `docs/product/PRODUCT_VISION_COLLABORATIVE_CARE.md`, `docs/product/PRODUCT_REFOUNDATION_ROADMAP.md`.
- Auditoria general: `docs/maintenance/PROJECT_REFOUNDATION_AUDIT_2026-07-10.md`.
- Desarrollo local y Auth: `docs/architecture/LOCAL_DEVELOPMENT_AUTH_PLAN.md`.
- Producto heredado: `docs/product/BETA_UX_AND_TESTING_PLAN.md`, `docs/product/PRODUCT_DESIGN_AUDIT_BACKLOG.md`, `docs/product/ROADMAP.md`, `docs/product/REQUISITOS_BETA_1.md`; usar como contexto, no como prioridad actual.
- Arquitectura futura: `docs/architecture/PLAN_ARQUITECTURA.md`, `docs/architecture/DATA_AI_SUPABASE_PLAN.md`, `docs/architecture/PLANT_CREATION_V2.md`.
- Diagramas: `docs/architecture/diagrams/README.md`.
- Proceso de equipo: `docs/process/WORKFLOW.md`, `docs/process/TEAM.md`, `docs/process/WEEKLY_EXECUTION.md`.
- Deploy: `docs/process/VERCEL_SUPABASE_DEPLOY.md`, `docs/process/SMOKE_TEST.md`.
- DevOps academico: `docs/devops/EP2_DEVOPS_REPORT.md`.

## Reglas de lectura

- No abras documentos largos si el brief, el backlog o el usuario no los citan.
- Si un documento antiguo contradice `DATABASE_STATE.md`, manda `DATABASE_STATE.md`.
- Si una tarea requiere continuidad futura, dejala en `docs/ai-inbox/PENDING_TASKS.md`.
- Si una auditoria detecta oportunidades, proponlas como hallazgos aprobables antes de implementar.
