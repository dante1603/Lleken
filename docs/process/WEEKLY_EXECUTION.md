# Ejecucion semanal

Este archivo queda como entrada corta para humanos y chats de IA.

- Guia del sistema de tareas: `TASK_SYSTEM.md`
- Tareas vivas de la semana: `WEEKLY_TASKS.md`
- Dashboard simple para navegador: `task-dashboard.html`
- Onboarding de integrantes con IA: `AI_MEMBER_ONBOARDING.md`

## Uso rapido

Para saber que le toca a cada integrante, leer `WEEKLY_TASKS.md`.

Para verlo en navegador, abrir `docs/process/task-dashboard.html`.

Para entender como funcionan tareas asignadas, disponibles, estados y criterios, leer `TASK_SYSTEM.md`.

## Preguntas utiles para IA

```text
Soy [Nombre]. Lee docs/process/AI_MEMBER_ONBOARDING.md y dime que me toca hoy.
```

```text
Soy [Nombre]. Lee docs/process/AI_MEMBER_ONBOARDING.md y dime que hay disponible para tomar.
```

La semana activa esta definida en `WEEKLY_TASKS.md`.
