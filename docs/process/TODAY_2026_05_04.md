## Objetivo del dia

- Vercel como hosting/API para el primer despliegue testeable.

## Hallazgo Vercel 1

Hora: despues del primer deploy manual en Vercel.

El deploy de `lleken.vercel.app` quedo "Listo", pero el login fallo en navegador con:

```text
Firebase: Error (auth/unauthorized-domain)
```

Interpretacion:

- No es un problema de Supabase como base de datos.
- No conviene resolverlo agregando dominios a Firebase como camino principal.
- El bundle publicado todavia esta usando Firebase Auth.
- El repo local actual ya tiene `AuthContext.tsx` usando Supabase Auth, por lo que Vercel probablemente desplego una rama/commit anterior.

Siguiente accion:

- Revisar en Vercel que rama esta configurada como Production Branch.
- Publicar la rama/commit que contiene la migracion Supabase antes de seguir probando login.
- Repetir smoke test solo despues de confirmar que el bundle publicado ya no carga login Firebase.

## Hallazgo Vercel 2

Hora: durante el primer intento de crear una planta en produccion.

La creacion de planta fallo inicialmente porque el backend Express local (`npm run dev:api`) no existe como proceso persistente en Vercel. En produccion Vercel hace:

```text
npm run build
api/*.ts -> Vercel Functions
```

No ejecuta:

```text
npm run dev
npm run dev:api
```

Accion tomada:

- Se dejo Vercel como hosting + funciones serverless.
- Se mantuvo Supabase como Auth, Postgres y Storage.
- Se reemplazo la ruta catch-all `api/[...path].ts` por funciones planas.
- Se redujo el numero de funciones para respetar el limite Hobby.

## Hallazgo Vercel 3

Vercel Hobby bloqueo un deploy porque no permite mas de 12 Serverless Functions por deployment.

El problema fue creado por funciones duplicadas y de diagnostico agregadas durante debugging.

Accion tomada:

- Se eliminaron funciones diagnosticas y duplicadas.
- El proyecto quedo con 7 funciones:
  - `api/health.ts`
  - `api/location-search.ts`
  - `api/location-reverse.ts`
  - `api/ai-identify-plant.ts`
  - `api/ai-care-plan.ts`
  - `api/ai-follow-up.ts`
  - `api/ai-refresh-plant-from-photo.ts`
- Commit final de limpieza: `6dab944 fix: stay under Vercel Hobby function limit`.
